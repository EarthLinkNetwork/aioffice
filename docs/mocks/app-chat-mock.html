メニューの置き方（2026-11-14 改訂）

  • 下のタブは毎日使うもの: 受信箱（判断）・秘書（話す）・Daily Times（毎日読む）・会社（部署ごとのサマリー）。
  • 秘書は 1 回で話せる。 自分で片付かない話は担当に回し、結果を返す（今日のカレンダーの件と同じ形）。
  • 担当は 3 つの道から: 会社 → 部署 → 担当／判断の件の「決められない — 担当と話す」／秘書に頼む。
  • 設定は右上の ⚙️（めったに開かない）。

仕組み（作る所）

場所作るもの
Paperclip（開発元の会社）担当「秘書」を足す（決まり kit/agents/secretary.md・担当に課題を回せる）。話 1 件 = 課題 1 件、発言 = comment。
plugin「mobile」（aioffice）話の一覧・発言の受け渡し（アプリの発言を課題の comment にし、担当を課題つきで起こす。担当の返事を通知 API へ返す）。担当の一覧を渡す。
通知 API（開発元）話（thread）と発言（message）の口と保存。返事が来たら push（題と最初の 1 行）。
アプリ（aioffice）①〜⑥ の画面。下のタブを受信箱・秘書・Daily Times・会社に・設定は右上へ。
会社の状況・Daily Times（開発元・plugin）部署ごとのサマリー（要約・注意・担当の動き）と Daily Times の号を plugin 経由で渡す。部署は担当の分け方（設定で持つ）。

まだ決めていないこと

  • 返事の速さ: 担当は起こされてから動くので、1 回の返事に 30 秒〜数分かかる（その間は「考えています…」を出す）。
  • 費用: 1 回の発言ごとに担当が 1 回動く（Paperclip の担当の実行の費用）。
