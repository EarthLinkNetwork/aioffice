# アプリの判断の件を 1 回押したら送る・押しても何も出ない、を無くす（build 5）の範囲

## 保証すること
- 判断の件（decision・interaction）は、選択肢を 1 回押すと、その操作を通知 API に送る。理由が要る操作（needsNote）は理由の欄を出し、理由が空なら送らない。外への送信・お金・取り消せない件（risk が internal でない）は確かめの画面を挟む。
- 押した操作は、通信の失敗・20 秒の無応答・401・サーバーの失敗（409 を含む）のどれでも、例外にならず、画面の知らせに文が出る。画面は「送っています…」のまま固まらない。
- 送っている間は、ほかの選択肢を押せない（二重の送信をしない）。押せないボタンは薄く見える。

## 保証しないこと
- 承認の件（approval）の流れの変更（承認／却下のボタンは今のまま。固まらない直しと文言だけ）。
- 通知 API（開発元）の側の変更。plugin の側の変更。
- 送った後に Paperclip で断られた操作をアプリに戻すこと（別件）。

## 前提
- 通知 API は 409 action-already-pending・400 note-required・invalid-action を返す（開発元の通知 API v0.4.3）。
- card.actions の needsNote は通知 API が付ける。

## 受け入れる限界
- 20 秒で止めた時、サーバーには届いていることがある。もう一度押すと 409 で「送信済み」と出る。

## user の裁定
- 2026-11-13: アプリの判断の画面は「選択肢を押したら送る」（選択肢で決定）。お金・外への送信・取り消せない件だけ確かめを挟む。
