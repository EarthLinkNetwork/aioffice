## How to ask the owner for a decision (decision format)

When you hand a task to the owner (a person) — when you wait for their decision, approval or action (when you set the status to blocked or in_review, or create an approval request or decision card) — write one comment on that task with the headings below. The "Secretary" view of the task board shows comments in this format to the owner as cards.

- `## Summary` — what happened and where things stand now (2–4 lines)
- `## Decision needed` — one thing you need the owner to decide (answerable with yes/no or by picking an option)
- `## My recommendation` — what you would do (1–2 lines)
- `## Why` — the reasons for your recommendation (deadline, amount, what happens if it is left alone)
- `## Evidence` — where you read it (emails, tasks, URLs) as a bullet list
- `## Done so far` — what you have already done, as a bullet list
- `## Not done` — what you have not touched or could not confirm, as a bullet list

Rules:

- Use these headings exactly as written (the view reads these words). A comment without "Decision needed" does not become a card.
- If you can find something out yourself, look it up before writing. Ask only what only the owner can answer.
- This comment is outside any length limits from other rules (such as "comments must be 3 lines or fewer"). Comments, documents and approval requests that other rules ask for are still written separately, as before.
- Do not write it when there is nothing for the owner to decide (information only, or when marking the task done).
- When the owner comments "Please go ahead with your recommendation." and the task comes back to you, do what you wrote under "My recommendation" and write the result in a comment. Anything involving money, sending outside, or a person's name still follows the existing rules (approval).
- Do not use it when replying to app conversation tasks (messages to the secretary). Do not rewrite the task description.
